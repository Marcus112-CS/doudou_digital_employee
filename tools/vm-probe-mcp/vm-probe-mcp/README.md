# VM Probe — 虚拟机巡检 MCP 工具

通过 SSH 采集远程 Linux 主机的基础信息与实时性能指标，并支持一键生成 PDF 巡检报告。
以 MCP（stdio）方式对外提供 3 个工具。

## 工具列表

| 工具 | 说明 |
|---|---|
| `probe_vm` | 探测**单台**主机，返回完整详情（基础信息、CPU、内存、磁盘分区与 IO、网络、Top5 进程） |
| `probe_vms` | **批量**并发探测多台主机（最多 50 台），返回每台一行摘要 + 成功/失败统计 |
| `generate_inspection_report` | 实时采集并生成**带封面的 PDF 巡检报告**，返回文件路径 |

## 采集内容

- **基础信息**：主机名、操作系统、内核、架构、CPU 型号与核数、内存总量与硬件规格（DDR 类型/频率，需 root）、Swap、虚拟化类型、IP 地址、运行时间、启动时间、系统时间、时区、当前登录用户、平均负载
- **性能指标**：CPU 使用率（含用户态/内核态/IO 等待拆解）、内存与 Swap 使用率、各磁盘分区使用率与读写速率、各网卡上下行速率与累计流量、CPU 占用 Top10 进程

## 参数说明

`hosts` 列表的每一项支持以下写法，后三项缺省时沿用 `username` / `password` / `port`：

```
10.0.0.1                      → 全部用默认值
10.0.0.1:2222                 → 自定义端口
root@10.0.0.1                 → 自定义用户
root:密码@10.0.0.1            → 自定义用户 + 密码
root:密码@10.0.0.1:2222       → 全部自定义
[2001:db8::1]:22              → IPv6
```

也支持传一个字符串，用逗号/空格/换行分隔多台：`"10.0.0.1,10.0.0.2,10.0.0.3"`。

## 前置条件

- 目标主机开启 SSH 服务，且所用账号可登录（只读采集，不做任何写操作）
- 目标主机为 Linux（依赖 `/proc`、`df`、`ps` 等标准命令）

## 依赖

```
mcp>=1.6.0            # 1.x / 2.x 均可，脚本已做兼容导入
paramiko>=3.4.0
reportlab>=4.0.0      # 仅 PDF 报告需要
```

> 关于 mcp 版本：1.x 用 `mcp.server.fastmcp.FastMCP`，2.x 改名为 `mcp.server.mcpserver.MCPServer`。
> 本脚本对两个大版本都做了兼容，实测 1.30.0 与 2.2.0 均可正常启动并调用。

## 告警阈值

| 指标 | 黄色告警 | 红色告警 |
|---|---|---|
| CPU 使用率 | ≥ 80% | ≥ 90% |
| 内存使用率 | ≥ 85% | ≥ 95% |
| 磁盘使用率 | ≥ 85% | ≥ 95% |

另外，1 分钟平均负载 ≥ CPU 核数时提示「系统负载偏高」。

## 说明

- 单台采集约 3-5 秒（CPU/网络/磁盘 IO 需要两次采样求差，保证是**实时值**而非开机以来的累计值）
- 批量采集并发执行，10 线程
- PDF 报告使用子集化中文字体，已随包附带，**无需目标机安装任何字体**
- 所有采集均为只读操作，不会修改目标主机的任何配置
